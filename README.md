# QuickQuiz - Application de Culture Générale (Flutter)

QuickQuiz est une application mobile multi-écrans Flutter développée dans un cadre académique. Elle intègre un logo  et propose des séries de quiz sur la **Culture Générale** (Géographie, Histoire, Sciences, Littérature, Cinéma).
